OFFICER ROSTER TRANSCRIPTION
============================

Volume:  {title}
Reader:  {reader}


TO START

  1. If this is still a zip file: right-click it, choose "Extract All...",
     and open the folder that creates. (The program cannot run from inside
     the zip.)

  2. Double-click  "Start Transcription".

     The first time, Windows may say "Windows protected your PC". Click
     "More info", then "Run anyway". This happens because the program is not
     from the Microsoft Store; it only runs from this folder and installs
     nothing.

  3. Your web browser opens on the first page that still needs reading.
     A small window also appears - keep it open while you work.


WHILE YOU WORK

  - Everything is saved as you go, inside this folder. You can stop at any
    time; next time it opens where you left off.
  - No internet connection is needed.
  - To stop, press "Quit" in the small window.


TO SEND IN YOUR WORK

  1. In the browser, press "Send in my work" (top right).
  2. A window opens showing a new file whose name starts with  roster-{pid}.
     (It is in the folder named "outbox" inside this folder.)
  3. {return_to}

  Send it whenever you like - each file holds everything you have done so
  far, so a later file replaces an earlier one. Please send one at least
  when you finish, and before you delete this folder: your work lives only
  here until it is sent.


IF SOMETHING GOES WRONG

  - Keep the whole folder together. Do not move "Start Transcription" out
    of it.
  - If it says the folder cannot be written to, move the whole folder to
    your Documents or Desktop and start it again.
  - Otherwise, send the file  data\logs\kit.log  to the person who gave
    you this kit.
