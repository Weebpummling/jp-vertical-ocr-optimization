# Secondary corpus — technical manuals

**Phase S. Begins only after the Officer Index main goal ships.**

Target documents: Sakae 21 and Sakae 12 engine handbooks; Zero (零戦) maintenance and operating
manuals. Each is a deliverable in its own right — a clean, modernized, translated table — and
collectively they are a **table-reading testbed** exercising the pipeline on engineering layouts
unlike the rosters.

Two distinct problems live here:

- **Datasheets and weight/limit tables** are numeric tables — the same template-registration
  approach as the rosters, just a second layout family.
- **Fuel and air performance charts are graphs, not tables.** Reading them means recovering data
  points from plotted curves — chart digitization (human-guided, WebPlotDigitizer-style), a
  separate capability scoped only to this track.

Plus a **document-modernization output mode**: transcribe a complex bracketed original faithfully,
then render a clean, translated, modern table.

> Scan contents are not committed to this repository. Personal-copy manuals stay local; store the
> reference (NDL PID, JACAR ref) here instead.
